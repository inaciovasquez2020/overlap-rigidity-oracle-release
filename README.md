# overlap-rigidity-oracle-release
Hidden-assignment oracle information bound. No general SAT hardness theorem is asserted.

## Download and verify

Download `overlap_scope_corrected.zip` and `overlap-release.zip.sha256` from the [Overlap Rigidity Oracle Snapshot](https://github.com/inaciovasquez2020/overlap-rigidity-oracle-release/releases/tag/snapshot-2026-11-01). In the download directory, run:

```bash
shasum -a 256 overlap_scope_corrected.zip
```

Compare the complete 64-character digest with the digest in `overlap-release.zip.sha256` before extracting the archive.
